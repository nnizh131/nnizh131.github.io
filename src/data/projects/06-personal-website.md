## Overview

I wanted a place to write that wasn't a third-party platform, loaded fast, and didn't require touching it every few months just to keep it running. Astro + a good theme is the answer.

## What's in it

- **Blog** — Markdown posts with syntax-highlighted code blocks and LaTeX support via KaTeX
- **Projects** — this page you're reading now
- **Dark mode** — system-aware with a manual toggle
- Static site, deployed to GitHub Pages, zero runtime dependencies

## Stack

- [Astro](https://astro.build) — static site generator
- [AstroPaper](https://github.com/satnaing/astro-paper) — theme
- Tailwind CSS — styling
- KaTeX — math rendering
- GitHub Actions — CI/CD to GitHub Pages
